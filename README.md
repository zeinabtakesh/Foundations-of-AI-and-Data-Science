# Foundations of AI and Data Science

This repository contains my personal notes and deep dives while independently studying **AI in Society - Foundations of AI and Data Science** by Prof. Gjergji Kasneci at the Technical University of Munich (TUM).

The textbook provides the main structure of the repository. For topics I want to understand more deeply, I expand with additional explanations, papers, people, architectures, historical context, diagrams, and implementations.

## Primary Reference

Gjergji Kasneci,  
*AI in Society - Foundations of AI and Data Science*,  
Technical University of Munich (TUM), Lecture Script.
